# 医師目線コンテンツの根拠メモ

## 公式情報

- 厚生労働省「災害時における健康管理」
  - URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/tiiki/saigai_00001.html
  - 災害時は避難所の気温上昇や片付け作業で熱中症に注意。停電時もこまめな水分・塩分補給、室内・外出時・衣服の工夫が必要。
  - 車など狭い座席で長時間足を動かさず、水分不足になると血栓ができ肺塞栓を誘発するおそれがある。対策として軽い運動・水分・飲酒制限・ゆったりした服装・ふくらはぎ運動・就寝時の下肢挙上を紹介。

- 厚生労働省「被災地における熱中症予防についてまとめました」
  - URL: https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/0000122500.html
  - 気温上昇下の片付け作業や車内避難で熱中症に注意し、水分・塩分補給等を推奨。

## 執筆方針

- 「医師監修」「Reviewed by」等の表示は、実際に有資格医師が内容を確認した記事だけに限定する。未確認の草稿は「医師の視点（草稿・公開前レビュー要）」と明示する。
- 個別の診断・薬の中止や変更を指示しない。緊急症状は119や現地の救護所・自治体の案内へ誘導する。
- 防災記事では、避難行動の一般原則と受診・救護の目安を分けて記載する。
