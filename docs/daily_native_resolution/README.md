# 個別実生成による印刷用4コマ

## 方式
4コマ全体を拡大せず、各場面を画像生成で独立して描画する。原稿は台詞・展開・注意書き・ALT・出典の固定基準とする。今回のパネルはすべて実出力1086×1448。4点を倍率1（切抜き・拡大なし）で2400×3200の3:4ページに貼り、タイトル・台詞・番号・注意書きを直接組版した。

## 実行
1. 同じ原画を参照に4場面を個別生成し、native_panels/panel1.png〜panel4.pngへ保存する。
2. 各絵を実見してキャラ・2本の腕/2つの手・ポーズ・背景・小道具を確認する。3コマ目の紙の文字は「家族の約束／集合場所／連絡方法」。
3. `python3 compose_native.py`。指定寸法以外のパネルは自動拡大せず停止する。
4. `python3 verify_native.py`。最終寸法・3:4・SHA・4枚の原寸貼付・組版領域外の画素完全一致・台詞一致を検証する。
5. 完成画像を実見し、文字切れ、手足、文字と場面、注意書き、ALT整合を別担当が確認する。自動検査だけで合格としない。
6. QA合格前、または長辺2400未達時は出荷用PRに進まない。X等の予約は別工程。

## 制約
生成結果自体は再実行で同じ絵にならない。保存されたネイティブ4点を入力とする合成工程は再現可能。細部・文字は画像生成任せにせず毎回目視する。全体の単純拡大・補間・超解像処理は用いない。API新規利用・追加契約なし、内蔵画像生成ツールのみ。

## 独立QA・画素根拠
制作担当と別のレビューで台詞・ALT・四肢・安全性を確認済み。タイトルと副題の間隔は狭めだが文字切れなし。各絵の実出力縦1448pxを原寸2段に配置しているため、余白や文字を除く絵自体の縦画素合計は2896px。キャンバスの余白を増やしただけの2400px達成ではない。
