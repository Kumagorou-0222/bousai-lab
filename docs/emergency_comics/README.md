# 災害時用4コマ保存庫

災害時に役立つ4コマ17本のPNG原本と、投稿文・ALT・出典・使用条件を保存しています。広告や商品紹介を目的としない防災資料です。

## 利用上の注意

- このフォルダは保存専用です。保存はSNSへの投稿・予約・自動配信への登録を意味しません。投稿の要否、対象地域、内容、時期は、その時点の状況を確認して人が判断してください。
- A〜Dのフェーズ区分や時間の目安は資料を整理するためのものです。行動を待つ時間ではありません。危険が迫る場合は、区分や時間にかかわらず安全確保・避難を優先してください。
- 最新の気象庁、自治体、消防・警察などの公式情報と、各資料の使用条件を確認してください。地域や現場の状況に応じた指示を優先します。
- 画像と対応する投稿文・ALT・出典を一組として確認してください。一般的な備えや判断の参考資料であり、個別の現場の安全を保証するものではありません。

## ファイル構成

- `images/`: PNG原本17本。画像は改変していません。
- `text/`: A01〜A03、A04〜A08、共通B〜Dの投稿文・ALT・出典・使用条件、計3文書。
- `manifest.json`: 各画像の識別子、寸法、バイト数、SHA-256、対応文書と出典。`purpose: archive-only` は保存専用であることを示します。既存の投稿承認台帳とは独立しています。

既存の記事、投稿予約、SNS承認台帳、自動化設定には登録していません。
