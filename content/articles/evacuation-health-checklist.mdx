## まずやること3つ

避難所で体調を崩さないために今すぐ準備すべきことはこの3つです。

1. **手指消毒液・マスクを防災袋に入れる**（感染症予防）
2. **耳栓・アイマスクを防災袋に入れる**（睡眠確保）
3. **水分補給の習慣をつける**（エコノミークラス症候群予防）

---

## 避難所の5大健康リスク

### 1. エコノミークラス症候群（深部静脈血栓症）

長時間同じ姿勢で座っていると、足の血管に血栓（血の塊）ができ、それが肺に移動して命に関わる状態（肺塞栓）になることがあります。

**車中泊**では特にリスクが高まります。

**予防方法：**
- 1〜2時間ごとに立ち上がり、5〜10分歩く
- 足首をぐるぐる回す（座ったままでも可）
- こまめに水分を補給する（アルコール・カフェインは避ける）
- 弾性ストッキング（医療用サポートストッキング）を使用する

### 2. 感染症（ノロウイルス・インフルエンザ・COVID-19）

多くの人が密集する避難所では、感染症が急速に広がります。阪神淡路・東日本大震災でも、避難所での感染症流行が大きな問題になりました。

**予防方法：**
- 手洗い（石鹸15秒以上 or アルコール消毒）
- マスク着用（咳・くしゃみがある場合は必須）
- トイレ後・食事前の手洗い徹底
- 嘔吐・下痢の症状がある方の隔離スペース確認
- 消毒液を自分で持参する

### 3. 食事・栄養の偏り

避難所の食事はおにぎり・パンなど炭水化物中心になりがちです。ビタミン・タンパク質が不足すると免疫が下がります。

**対策：**
- 野菜ジュース・マルチビタミンを防災袋に入れる
- 缶詰（サバ缶・ツナ缶）でタンパク質を補う
- 高齢者・子どもは特に栄養不足になりやすい

### 4. 睡眠不足

騒音・照明・不安感で睡眠が取りにくくなります。慢性的な睡眠不足は免疫低下・判断力低下につながります。

**対策：**
- 耳栓・アイマスクを防災袋に入れる
- 就寝・起床時間をできるだけ一定に保つ
- 昼寝を短時間（20〜30分）で活用する
- プライバシーが確保できるスペースを確保する

### 5. 精神的ストレス・PTSD

被災のショック・避難生活の不自由さは精神的に大きな負担です。特に子ども・高齢者は影響を受けやすい。

**対策：**
- 規則正しい生活リズムを保つ
- 近所の方と積極的に会話する
- ラジオ・本・手芸など、気を紛らわせるものを持参する
- 子どもにはお気に入りのおもちゃや絵本を
- 無理に「大丈夫」と思わず、専門家の支援を求める

## 避難所でのチェックリスト

### 到着直後

- [ ] トイレの場所を確認
- [ ] 手洗い場所・消毒液の場所を確認
- [ ] 自分のスペースを確保（出口に近い場所が望ましい）
- [ ] 医療班・保健師の場所を確認
- [ ] 女性・子ども専用エリアを確認

### 毎日

- [ ] 1〜2時間ごとに立ち上がって歩く
- [ ] 水を最低1.5L/日飲む
- [ ] 手洗いを徹底する（特にトイレ後・食事前）
- [ ] 体調の変化を家族で確認し合う
- [ ] 起床・就寝時間をできるだけ一定にする

### 持参すると役立つもの

| アイテム | 目的 |
|---------|------|
| 手指消毒液 | 感染症予防 |
| マスク（多めに） | 感染症予防 |
| 耳栓・アイマスク | 睡眠確保 |
| 弾性ストッキング | 血栓予防 |
| 野菜ジュース・マルチビタミン | 栄養補完 |
| ウェットティッシュ | 断水時の清拭 |
| ラジオ・本・手芸道具 | ストレス発散 |

## こんな症状は要注意

以下の症状が現れた場合は、すぐに医療班に相談してください。

- 足のむくみ・痛み・赤み（血栓の可能性）
- 突然の息切れ・胸の痛み（肺塞栓の可能性）
- 38度以上の発熱・嘔吐・下痢（感染症の可能性）
- 強い不安感・眠れない・フラッシュバック（心理的ケアが必要）

## よくある間違い

| ❌ やりがちなこと | ⭕ 正しい対応 |
|---|---|
| 「動くと迷惑」と思って動かない | 定期的に外を歩いてOK。積極的に動く |
| 水分を控える（トイレが面倒） | 1.5L/日の水分補給は必須 |
| 体調が悪くても我慢する | 避難所の医療班・保健師にすぐ相談 |
| 食事が出るから何もしなくていい | 栄養補助食品・缶詰を自分で持参する |
