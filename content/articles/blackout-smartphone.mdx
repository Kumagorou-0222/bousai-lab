## 結論：今すぐやること3つ

停電してスマホを長持ちさせるには：

1. ⚡ **今すぐ低電力モード（省エネモード）にする**
2. 🔆 **画面の明るさを最低限まで下げる**
3. 📶 **使わないアプリ・通信をすべてオフにする**

---

## 今すぐやる行動チェックリスト

### iPhone の場合

- [ ] 設定 → バッテリー → 低電力モード をオン
- [ ] 画面の明るさを最低限まで下げる（コントロールセンターから）
- [ ] Wi-Fiをオフにする（電波が届かない場合）
- [ ] Bluetoothをオフにする
- [ ] 位置情報サービスをオフにする
- [ ] バックグラウンドアプリの更新をオフにする

### Android の場合

- [ ] 設定 → バッテリー → 省エネモード をオン
- [ ] 画面の明るさを最低限まで下げる
- [ ] Wi-Fi・Bluetoothをオフにする
- [ ] 位置情報をオフにする
- [ ] 不要なアプリの通知をオフにする

## やってはいけないこと

| ❌ NG行動 | 理由 |
|---|---|
| 動画・SNSを長時間見る | 電池が急速に減る |
| 画面輝度を最大にする | 輝度が最大の消費電力は大きい |
| 通話を長時間する | 通話は電力を消耗する |
| 充電が10%以下になるまで放置 | 緊急時に使えなくなる |
| 複数のアプリを同時に起動 | バックグラウンド処理で電力消費 |

## 状況別行動

### モバイルバッテリーがある場合

- 電池残量が**50%になったら充電開始**する（30%以下まで待たない）
- モバイルバッテリー自体の残量も確認する
- 複数台ある場合は、緊急連絡用のスマホを優先して充電

### 車がある場合

- 車のシガーソケット（USBポート）で充電できる
- ただし、**密閉した車内でエンジンをかけ続けない**（一酸化炭素中毒）
- 換気しながら短時間で充電する

### 充電手段がない場合

- できる限り**スマホを使わない**ことが最も有効
- 必要なときだけ起動し、用が済んだら電源オフ
- 大切な情報（家族の電話番号・避難場所）はあらかじめ紙にメモしておく

## スマホで確認すべき緊急情報

停電中のスマホは**情報収集ツール**として使うことを最優先にします：

1. **自治体の公式サイト・Xアカウント** — 避難情報・復旧予定
2. **NHKのウェブサイト** — 災害ニュース
3. **電力会社の停電情報** — 復旧見込み時間
4. **気象庁** — 台風・大雨情報

---

## 理由：なぜスマホの電池節約が重要なのか

災害時、スマホは**命綱**です。避難情報の取得・家族への連絡・緊急通報——これらはすべてスマホに依存しています。電池が切れた瞬間、これらすべてが使えなくなります。  
「電池が残っていれば…」という後悔をしないために、停電直後の節約設定が重要です。
