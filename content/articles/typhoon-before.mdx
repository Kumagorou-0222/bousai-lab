## 結論：今すぐやること3つ

台風前日にやることは：

1. 📦 **外にある物をすべて屋内に入れる**
2. 💧 **飲料水と生活用水を確保する**
3. 📱 **スマホ・モバイルバッテリーを満充電にする**

---

## 今すぐやる行動チェックリスト

### 屋外の安全確保

- [ ] 植木鉢・プランターを屋内へ移動
- [ ] 物干し竿・ハンガーを外す（室内へ）
- [ ] 自転車を縛るか屋内へ入れる
- [ ] ゴミ箱を固定するか屋内へ
- [ ] 看板・表示物を固定または撤去
- [ ] 排水溝・側溝を掃除する（詰まりによる浸水防止）

### 水・食料の確保

- [ ] 飲料水を1人3L×日数分確保する
- [ ] 浴槽に水を満タンに溜める（生活用水）
- [ ] 食料3日分を確認する（カセットコンロも確認）
- [ ] 薬・医療品の在庫を確認する

### 電源・情報の確保

- [ ] スマホを満充電にする
- [ ] モバイルバッテリーを満充電にする
- [ ] ラジオの電池を確認する
- [ ] 懐中電灯の電池を確認する
- [ ] ポータブル電源があれば充電する

### 窓の補強

- [ ] 雨戸・シャッターを閉める
- [ ] 雨戸がない窓には養生テープを貼る
- [ ] 窓の鍵が閉まっているか確認する

## やってはいけないこと

| ❌ NG行動 | 理由 |
|---|---|
| 外の物を放置する | 強風で飛んで人・窓を傷つける |
| 準備を当日朝に回す | 強風・大雨の中では作業できない |
| 水の確保を後回しにする | 断水になってからでは遅い |
| 河川・海岸の様子を見に行く | 急な増水・高波で流される |
| スマホの充電を後回しにする | 停電になると充電できない |

## 状況別行動

### マンション・アパートの場合

ベランダの植木鉢・物干し竿は特に危険です。強風で飛ぶと、下の階や隣の部屋の窓を割る可能性があります。**必ず前日のうちに室内へ**。

### 一戸建ての場合

雨樋の詰まりを確認・掃除する。詰まると雨水があふれて建物内部に浸水します。また、屋根の損傷がある場合は台風前に修理業者に連絡を。

### 低地・川の近くに住んでいる場合

自治体のハザードマップを確認し、必要なら**台風上陸前に避難**することを検討してください。  
→ [台風のとき避難が必要な判断基準](/articles/typhoon-evacuation)

## 理由：なぜ前日の準備が重要なのか

台風当日は強風・大雨の中での屋外作業が困難または危険です。  
「当日やればいい」と思っていると、強風の中で物干し竿を取り込もうとして転倒するケースが毎年起きています。  
**前日のうちに全て完了させること**が、台風対策の鉄則です。
