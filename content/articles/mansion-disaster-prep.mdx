## まずやること3つ

マンション住まいの方が今すぐ確認すべきことはこの3つです。

1. **水・食料を7日分以上備蓄する**（エレベーター停止で補充困難になるため）
2. **携帯トイレを50回分以上用意する**（断水でトイレが使えなくなる）
3. **管理組合の防災対応を確認する**（非常用発電機・給水設備の有無）

---

## マンション特有の3つのリスク

### 1. エレベーターが止まる

震度5強以上でエレベーターは自動停止します。専門業者の点検が終わるまで使用禁止です。

高層階に住んでいると、**水や食料を補充しに外へ出ること自体が困難**になります。「何日か外出できなくなる」前提で備蓄を準備してください。

### 2. 断水リスクが高い

多くのマンションは「受水タンク方式」です。**停電するとポンプが止まり、断水が即発生**します。

地震で建物内配管が損傷すると、復旧まで数週間かかることも。1人1日3L×7日分=**最低21L**を事前に用意してください。

### 3. 在宅避難が長期化しやすい

マンションは構造上、建物が無事なら外に避難しない方が安全なケースが多いです。**「7日間、自力で過ごせる備蓄」**が在宅避難の目安です。

## マンション防災チェックリスト

### 備蓄【最優先】

- [ ] 水：1人21L以上（2Lペットボトル×11本/人）
- [ ] 食料：7日分のレトルト・缶詰・アルファ米
- [ ] 携帯トイレ：50回分以上/人
- [ ] モバイルバッテリー：20,000mAh以上
- [ ] LEDランタン：乾電池式
- [ ] 現金：少額紙幣・硬貨（ATMが止まる）

### 家具固定【命に直結】

- [ ] 寝室のタンス・本棚に突っ張り棒を設置
- [ ] 冷蔵庫を耐震ベルトで壁に固定
- [ ] 食器棚の扉に耐震ラッチを設置
- [ ] テレビ台に耐震シートを貼る

### 情報・連絡

- [ ] 管理組合の連絡先を確認
- [ ] マンションの防災マニュアルを入手
- [ ] 非常用発電機の有無・使える家電を確認
- [ ] 家族との集合場所・連絡方法を決める

### 避難経路

- [ ] 非常階段の場所を全員が把握
- [ ] 夜間・停電時でも安全に降りられるか確認
- [ ] 避難口が鍵・物で塞がれていないか確認

## マンション特有の備え

| 備え | 理由 |
|------|------|
| 水21L以上/人 | エレベーター停止で補充困難 |
| 携帯トイレ50回分 | 断水で水洗トイレが使えなくなる |
| ポータブル電源 | 医療機器・扇風機を動かせる |
| ローリングストック | 期限切れを防ぐ |

---

## よくある間違い

| ❌ やりがちなこと | ⭕ 正しい対応 |
|---|---|
| 「避難所に行けばいい」と思う | 在宅避難が基本。避難所は最終手段 |
| 水2〜3日分だけ準備 | 7日分が目安。エレベーター停止で補充できない |
| 管理組合まかせにする | 家族の備蓄は自分で揃える |
| 非常用エレベーターがあると思う | 停電中は消防・救急用。住民は使えない |

---

## 管理組合に確認すること

1. **非常用発電機**の有無・どの設備が動くか（エレベーター？共用廊下の照明？）
2. **給水設備の構造**（受水タンク方式なら停電で断水する）
3. **防災マニュアル**の入手方法
4. **避難訓練**の実施状況と参加方法
5. **耐震補強工事**の実施状況

管理組合が防災対応を整備していない場合は、**自分の家族分は自分で用意する**ことを前提にしてください。
