## 結論：今すぐやること3つ

長期停電（1日以上）のとき：

1. 🍱 **食品の状態を確認し、食べる順番を決める**
2. 💧 **水の確保状況を確認する（飲料水・生活用水）**
3. 🌡️ **体温維持の手段を確保する（熱中症・低体温症対策）**

---

## 今すぐやる行動チェックリスト

### 食料管理

- [ ] 冷蔵庫の食品の状態を確認（停電後4〜6時間で傷み始める）
- [ ] 傷みやすい順に食べる計画を立てる（肉・魚 → 乳製品 → 野菜・果物）
- [ ] 非常食・缶詰・レトルトの在庫を確認する
- [ ] カセットコンロ・ガスの残量を確認する

### 水の管理

- [ ] 飲料水の在庫を確認する（目安：1人1日3L）
- [ ] 浴槽に水を溜める（断水に備えた生活用水）
- [ ] 手洗い・食器洗いの水を節水する

### 体温維持

- [ ] 寒い場合：重ね着・毛布・カイロを用意する
- [ ] 暑い場合：扇風機（電池式）・日陰・水を使った冷却

### 情報収集

- [ ] 手回し・ソーラーラジオで復旧情報を確認
- [ ] 自治体の避難情報を定期的にチェック
- [ ] 復旧見込みが数日以上なら避難を検討する

## やってはいけないこと

| ❌ NG行動 | 理由 |
|---|---|
| 変な臭い・色の食品を食べる | 食中毒になる |
| 一酸化炭素が出る機器を室内で使う | 死亡事故になる（BBQコンロ・発電機など） |
| 水を無駄使いする | 断水になると生死に関わる |
| 停電の長期化を過小評価して何も準備しない | 後手後手で悪化する |
| 復旧を待ちながら何もしない | 体調悪化・孤立化のリスク |

## 状況別行動

### 停電1〜2日目

**最優先：食品管理**
- 停電後4〜6時間：肉・魚・乳製品を食べるか保存を判断
- 停電後8〜12時間：冷蔵食品の多くが傷み始める
- 停電後24時間：冷凍食品も解凍が始まる

食べる順番のルール：
1. 生もの（肉・魚・刺身）
2. 乳製品（ヨーグルト・チーズ）
3. 野菜・果物
4. 缶詰・レトルト・乾物

### 停電3〜7日目

**体温維持が命を守る**
- 夏：熱中症対策（水分・塩分補給・日陰・冷却）
- 冬：低体温症対策（重ね着・毛布・使い捨てカイロ）

**避難を真剣に検討する目安：**
- 室温が夏に35℃以上、冬に10℃以下になる
- 飲料水が底をつく
- 医療が必要な状態になる

### 停電1週間以上

長期停電は通常、大規模な自然災害時に発生します。この場合は**避難所への移動**を検討してください。

## 理由：なぜ長期停電の想定が重要なのか

近年の大規模災害では、停電が1週間以上続くケースが報告されています（2018年北海道胆振東部地震など）。「すぐに復旧するだろう」という楽観は命取りです。  
「最低3日、できれば1週間」の停電を想定して備えておくことが、今後の防災の基準です。
