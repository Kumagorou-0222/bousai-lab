```
4-koma manga style, chibi cute characters, clean line art, bright flat colors, white background, Japanese manga speech bubbles with black outline, professional illustration quality, no watermark.
Characters: "riss" = chibi squirrel wearing yellow safety helmet and orange safety vest, round chubby body, expressive eyes. "robot" = chibi blue-and-white robot with square head, "Q" letter on chest, antenna, friendly glowing blue eyes.
```

## 生成後の手順

1. 各パネルを `public/manga/【フォルダ名】/panel-01.png` 〜 `panel-04.png` として保存
2. 以下を記事MDXの `manga:` の直前に追加（フォルダ名は記事ごとに変える）：

```yaml
mangaImages:
  - "/manga/【フォルダ名】/panel-01.png"
  - "/manga/【フォルダ名】/panel-02.png"
  - "/manga/【フォルダ名】/panel-03.png"
  - "/manga/【フォルダ名】/panel-04.png"
```

3. `git add . && git commit -m "Add: 漫画画像追加" && git push`
